Beginner's Handbook

Quest & Dialogue Integration

A simple, direct developer guide designed to get you creating quests, monitoring progress, managing dialogue routes, and issuing items or currency in Game Project Toris.

1. Core Quest States

Pixel Crushers' Dialogue System manages the source of truth for all active quests. When creating a quest, it naturally shifts through a strict set of states to represent its life cycle:

Unassigned
Created, but player hasn't accepted it yet
→
Active
The quest is in progress in the player's journal
→
ReturnToNPC
Objectives complete. Ready to turn in
→
Success
Finished! Reward granted and closed

2. Setup NPC Conversations (No Coding Required)

You can configure NPCs to play completely different dialogue flows based on the player's quest state simply by setting up the PixelCrushersConversationInteractable component.

How to Configure:

  1. Add the PixelCrushersConversationInteractable component to your NPC's root GameObject.
  2. Set a Default Conversation (e.g. Guide_Intro) to play when the NPC has no relevant tasks to offer.
  3. Add custom entries to the Quest Conversation Routes array to bind quest state to conversation files:

💡 Quest Route Setup Example:

  • Quest Name: AxeQuest
  • Conversation When Unassigned: AxeQuest_Offer (NPC asks for help)
  • Conversation When Active: AxeQuest_Reminder (NPC tells you to hurry up)
  • Conversation When Return To NPC: AxeQuest_TurnIn (NPC takes wood and completes quest)
  • Conversation When Success: AxeQuest_CompleteTalk (NPC says "Thanks again!")

3. Tracking Objectives (Gameplay Progress)

When players complete tasks in the world (e.g. killing a monster or exploring a location), your code reports these events to the quest manager via the QuestFact API.

Reporting Gameplay Events in C#

Simply call the reporter when the achievement occurs in your code:

// Example: When a player defeats a Slime
QuestFact killFact = QuestFact.KillEnemy("SlimeNPC", "Slime", 1);
PixelCrushersQuestFactReporter.Report(killFact);

// Example: When a player enters the "AncientTemple" zone
QuestFact exploreFact = QuestFact.ExploreArea("AncientTemple", 1);
PixelCrushersQuestFactReporter.Report(exploreFact);

The scene's active PixelCrushersQuestProgressMapper automatically captures these reported facts and safely increments corresponding variables in the active quest database.

4. Dialogue Editor Lua Scripting Cheat Sheet

Inside the Pixel Crushers Dialogue Editor, you can place checks in the Conditions field or execute actions in the Script field of any dialogue line.

Conditions (Branching Decisions)

Dialogue Node Condition (Lua) Description
TorisHasItem("Wood", 5) Checks if the player has 5 pieces of Wood in their inventory.
TorisGetItemCount("WolfPelt") >= 3 Checks if the player has at least 3 Wolf Pelts.
TorisGetGold() >= 100 Checks if the player has 100 or more gold.
Quest["AxeQuest"].State == "active" Checks if the quest "AxeQuest" is currently active.

Scripts (Handovers & State Changes)

Dialogue Node User Script (Lua) Description
TorisTakeItem("Wood", 5) Safely removes 5 pieces of Wood from the backpack.
TorisGiveItem("Axe", 1) Adds 1 Axe to the player's inventory slots.
TorisGiveGold(150) Adds 150 gold directly to the player's progression wallet.
Quest["AxeQuest"].State = "success" Marks the quest as successfully completed.

5. Giving Rewards on Quest Completion

You have two primary ways to set up quest rewards in your Toris project:

Approach A: Visual Config (Recommended)

Use the visual Reward Adapter which maps items and progression changes directly inside the Editor:

  • Create a PixelCrushersQuestRewardSetSO ScriptableObject asset in your project directories.
  • Add a reward entry matching your quest name (e.g. AxeQuest).
  • Fill in the visual slots: Gold Reward, XP Reward, and drag static InventoryItemSO assets.
  • Ensure the PixelCrushersQuestRewardAdapter script is attached to a GameObject in your scene. It automatically watches quest states and grants the reward package the moment a quest reaches Success.

Approach B: Inline Conversational Rewards (Dialogue Node)

If you prefer an NPC to reward the player dynamically during a dialogue branch, put the calls inside the dialogue node's Script field:

-- Hand out rewards in the turn-in dialogue line
TorisGiveGold(150);
TorisGiveItem("SteelSword", 1);
Quest["SwordQuest"].State = "success";

6. C# API Code Cheat Sheet

If you are writing custom gameplay code (e.g. hitting a trigger zone, clicking a custom button, or completing a challenge) and need to query or update quest values, interact with the static PixelCrushersQuestBridge helper: 

using PixelCrushers.DialogueSystem;

// 1. Check if a quest is active
bool active = PixelCrushersQuestBridge.GetQuestState("MyQuest") == QuestState.Active;

// 2. Start a quest (sets state to active)
PixelCrushersQuestBridge.StartQuest("MyQuest");

// 3. Update or Complete a quest
PixelCrushersQuestBridge.SetQuestState("MyQuest", QuestState.ReturnToNPC); // Ready to turn in
PixelCrushersQuestBridge.SetQuestState("MyQuest", QuestState.Success);     // Fully completed

// 4. Manage quest entries (individual checklist tasks within a quest)
PixelCrushersQuestBridge.SetQuestEntryState("MyQuest", 1, QuestState.Success);

// 5. Manipulate global variables
int killCount = PixelCrushersQuestBridge.GetIntVariable("Slime_Kills");
PixelCrushersQuestBridge.IncrementIntVariable("Slime_Kills", 1);

7. Checklist for Creating Your First Quest

Follow this simple step-by-step checklist to set up a brand new quest from scratch in your project:

1
Define in Dialogue Database
Open the Pixel Crushers Dialogue Editor, navigate to the Quests tab, create a new quest, set its ID (e.g. SlimeHunter), title, description, and leave its state as Unassigned.
2
Assign NPC Routes
Select your NPC GameObject, attach the PixelCrushersConversationInteractable component, and add a route mapping SlimeHunter to its corresponding offer, active, and success conversation titles.
3
Draft Dialogue Branches
Create the dialogue trees. On the quest acceptance node, set the Script field to: Quest["SlimeHunter"].State = "active". On the turn-in node, check item conditions and transition the state to success: Quest["SlimeHunter"].State = "success".
4
Configure Rewards
Use the C# Lua bridge functions directly inside dialogue scripts to hand over gold and potions, or create a PixelCrushersQuestRewardSetSO asset and map the rewards visually.
